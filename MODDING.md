# Моды для Wreckbox

Мод — это небольшой текстовый файл `.wmod`. Он добавляет в игру своё: инструменты, оружие, предметы, материалы, здания, карты, звуки,
правила и мини-игры. Мод ставится в меню игры («Моды» → «Добавить файл»), включается и выключается одним переключателем и не мешает
обновлениям игры: вышла новая версия — моды работают дальше.

Документ написан сразу для трёх читателей:

- **без программирования** — раздел 1: мод с постройкой или картой делается в редакторе за минуту, без единой строчки кода;
- **для тех, кто попросит нейросеть** — раздел 8: приложите этот файл к просьбе, там есть правила для нейросети и готовый текст просьбы;
- **для программистов** — разделы 2–7: основы, полный справочник команд, пределы, готовые моды целиком и отладка.

Все примеры кода в этом документе настоящие: игра проверяет каждый из них автотестом перед выпуском. Если пример не работает
в вашей версии игры — обновите игру.

Этот документ есть и [на английском](MODDING.en.md) (English version). Готовые моды-примеры — в папке [examples](examples).

## 1. Мод без кода: постройка или карта из редактора

Игра сама собирает мод из того, что вы построили.

**Здание.** Постройте дом — в «Стройке» или в редакторе карт («Карты» → «Своя карта»).

1. Выберите инструмент «Копировать» и обведите дом рамкой.
2. Нажмите «В мод» → «Постройка из рамки».
3. Впишите название и автора, нажмите «Сохранить файл». Получится файл `название.wmod`.
4. Поставьте мод: меню → «Моды» → «Добавить файл».

Дом появится в инструменте «Здание» («Стройка» → «Здание») — у вас и у каждого, кто поставит мод. Он встаёт на участок, как дома
игры: участок расчищается и выравнивается, в дом заселяются жители, если в нём есть комнаты, двери и лестницы.

**Карта.** Сделайте карту в редакторе («Карты» → «Своя карта» → «Создать карту»), нажмите «⋯» → «Сделать мод» → «Эта карта».
После установки мода карта появится в «Моих картах» («Карты» → «Своя карта» → «Открыть список») с пометкой «мод»: её можно
открыть для игры или в редакторе.

**Что внутри такого файла.** Обычный мод: несколько строк и одна длинная строка данных в конце. Её не нужно ни читать, ни править.
Файл можно открыть в Блокноте и дописать в него своё — например, инструмент рядом с домом (раздел 6.9).

<!-- test: skip — вид файла, данные не настоящие -->
```js
// Мод для Wreckbox: здание «Дом с башенкой». Собран в редакторе карт: «⋯» → «Сделать мод».
Wreck.mod({
  id: 'dom-s-bashenkoy-k3f9a',
  name: "Дом с башенкой",
  author: "Ваше имя",
  version: '1.0',
  api: 1,
  description: "Новое здание в инструменте «Здание» — в «Стройке» и в редакторе карт.",
  setup(w) {
    w.addBuilding({ id: 'b1', name: "Дом с башенкой", data: DATA });
  },
});
const DATA = 'V0JMRAEAAAA…';   // данные постройки — длинная строка
```

## 2. Первый мод за пять минут

### 2.1. Шаблон

Скопируйте это в Блокнот целиком:

```js
// Хлопушка — мой первый мод для Wreckbox.
Wreck.mod({
  id: 'hlopushka',                       // имя мода латиницей: по нему игра отличает моды друг от друга
  name: { ru: 'Хлопушка', en: 'Popper' },
  author: 'Ваше имя',
  version: '1.0',
  api: 1,                                // версия формата модов — пока всегда 1
  description: 'Инструмент «Хлопушка»: маленький взрыв там, где коснулись.',

  setup(w) {                             // w — пульт: через него мод делает всё
    w.addTool({
      id: 'popper',
      name: { ru: 'Хлопушка', en: 'Popper' },
      hint: { ru: 'Коснитесь стены или земли.', en: 'Tap a wall or the ground.' },
      slider: { label: { ru: 'Сила', en: 'Power' }, min: 1, max: 10, def: 3 },

      down(p) {                          // касание: p.x, p.y — точка в мире, p.value — ползунок
        w.explode(p.x, p.y, 10 + p.value * 4, 60 + p.value * 40);
      },
    });
  },
});
```

### 2.2. Как поставить

1. Сохраните файл с именем `hlopushka.wmod`. В Блокноте: «Файл» → «Сохранить как», тип «Все файлы», кодировка UTF-8.
2. В игре: меню → «Моды» → «Добавить файл» и выберите файл. На телефоне удобнее «Вставить текст»: скопируйте весь текст мода
   и вставьте в поле.
3. Игра покажет предупреждение («мод — это программа»). Нажмите «Добавить мод».

### 2.3. Как проверить

Откройте «Снос»: в ряду инструментов, перед ластиком, появилась «Хлопушка». Выберите её, подвиньте ползунок, коснитесь стены.
В меню «Моды» у мода видно, что он добавил («Инструменты: Хлопушка»), а внизу меню — «1 мод».

### 2.4. Как поправить

Поменяйте текст и добавьте мод снова. **Мод с тем же `id` заменяет прежний** — так выпускаются новые версии: `id` оставьте, поднимите
`version`. Сохранённые данные мода (раздел 4.10) при замене остаются.

Если мод не добавился, игра скажет почему: «Не удалось добавить мод: …». Частые причины и что с ними делать — раздел 7.

## 3. Основы

### 3.1. Устройство файла

Весь мод — один вызов `Wreck.mod({ … })`. В фигурных скобках — описание мода:

| Поле | Что это | Обязательно |
|---|---|---|
| `id` | Имя мода латиницей: буквы, цифры, `-` и `_`, до 24 знаков | Желательно (без него игра придумает `id` по названию и автору) |
| `name` | Название — строкой или на двух языках: `{ ru: '…', en: '…' }`, до 40 знаков | Да |
| `author` | Автор | Нет |
| `version` | Версия мода: `'1.0'`, `'1.2.3'` | Нет |
| `api` | Версия формата модов. Сейчас всегда `1` | Да |
| `description` | Короткое описание в строке мода в меню «Моды», до 220 знаков (длиннее — обрежется с «…», а целиком откроется кнопкой «Подробнее») | Нет |
| `details` | Подробное описание до 4000 знаков: тонкости, правила, команды, советы. Переносы строк сохраняются. Строкой или на двух языках. Есть — у мода кнопка «Подробнее» | Нет |
| `setup(w)` | Функция, которую игра зовёт при включении мода. `w` — пульт | Да |

Вне `setup` можно объявлять свои постоянные и функции (как `const DATA = '…'` в моде из редактора). Всё остальное делается
внутри `setup`: там мод добавляет инструменты, предметы и подписывается на события.

`setup` выполняется **один раз** при включении мода: при установке, при запуске игры и когда игрок включает мод переключателем.
Функции, которые мод отдал игре (касание инструмента, обработчик события), игра зовёт потом, когда придёт время.

### 3.2. `id` и имена

- **`id` мода** отличает его от других модов. Два мода с одним `id` не стоят рядом — второй заменяет первый. Придумайте своё:
  `ufo-invasion`, `petya-tools`.
- **`id` внутри мода** (у инструмента, предмета, материала, звука, здания, карты) — короткие, латиницей: `'cluster'`, `'titan'`.
  Они должны быть разными внутри одного вида: два инструмента `'boom'` в одном моде — ошибка. У разных модов совпадать могут:
  игра сама дописывает к ним `id` мода.
- **Названия** — всё, что видит игрок (`name`, `hint`, подпись ползунка), — пишите на двух языках: `{ ru: 'Титан', en: 'Titanium' }`.
  Игра покажет нужный. Можно и просто строкой — тогда она видна на обоих языках. Язык игры — `w.lang` (`'ru'` или `'en'`).

### 3.3. Координаты

- Мир — разрез города. **Ось `x` — вправо, ось `y` — вниз**: чем больше `y`, тем ниже. Единица — **пиксель мира**.
- Мир состоит из **клеток 6 × 6 пикселей** (`w.cell` = 6). Клетка — это `col` (столбец) и `row` (строка):
  `col = Math.floor(x / w.cell)`, `row = Math.floor(y / w.cell)`. Центр клетки: `x = (col + 0.5) * w.cell`.
- Масштаб: 1 метр — около 15 пикселей (2,5 клетки). Этаж дома — около 8 клеток.
- Ширина мира у каждой карты своя: `w.world.width`. Земля везде на своей высоте: `w.groundY(x)` — верх грунта в точке `x`,
  `w.topY(x)` — верх всего твёрдого (крыша, если над этой точкой дом).
- Что сейчас на экране: `w.camera` — `{ x, y, zoom, left, top, right, bottom }` (центр, приближение и края кадра в пикселях мира).

В примерах справочника (раздел 4) `x`, `y` — точка в мире, `col`, `row` — клетка. В своём моде берите их из касания (`p.x`, `p.y`),
из события (`e.x`, `e.y`) или из камеры.

### 3.4. Время, скорость, сила тяжести

- Время — **в секундах игры**. Игра считается шагами по 1/60 секунды. На паузе время стоит; если игрок ускорил игру, шагов
  в секунду больше. `w.world.time` — сколько секунд идёт этот мир.
- Скорость — **пиксели в секунду** (`vx` — вправо, `vy` — вниз; подбросить вверх — отрицательная `vy`).
- Сила тяжести «1g» — 450 пикселей в секунду за секунду. `w.world.gravity` — нынешняя, в g (1 — земная, 0 — невесомость).

### 3.5. Сила взрывов и бед

Взрыв задают два числа: **радиус** (пиксели) и **мощность** (сколько прочности он снимает с блоков). Для сравнения:

| Что | Радиус | Мощность |
|---|---|---|
| Хлопушка, петарда | 10–20 | 50–120 |
| Газовый баллон | 46 | 340 |
| Бомба игры (ползунок от 1 до 10) | 36–108 | 410–880 |
| Предел для мода | 200 | 2000 |

Большие беды (метеорит, смерч, цунами, ядерный удар…) задаются **уровнем от 1 до 10** — как ползунок у такого инструмента в игре.

### 3.6. Что возвращают команды

- Действие (`explode`, `setBlock`, `spawnItem`…) возвращает `true` — получилось, `false` — нет: место занято, точка за краем мира,
  кончился запас действий на этот шаг (раздел 5). На `false` игра не ругается — просто ничего не произошло.
- Если мод дал команде **неверные данные** (нет такого материала, звука, предмета, нет обязательного поля), команда бросает ошибку.
  Игрок увидит сообщение: «Мод «…»: ошибка — …». Ошибка в `setup` не даёт моду включиться.
- Сведения (`w.world`, `w.camera`, `findPeople`…) — **копии**. Поменять что-то в них нельзя: люди и предметы меняются только командами.

### 3.7. Что мод может и чего не может

Мод работает только через пульт `w`. Внутренних частей игры он не видит: в коде мода нет `window`, `document`, `fetch`,
`localStorage` и других средств страницы — они заменены пустыми. Обычный JavaScript есть весь: `Math`, `JSON`, `Date`, массивы,
функции, классы.

Для отложенных действий — `w.after(секунды, функция)`, а не `setTimeout`: `w.after` идёт по времени игры, стоит на паузе и не
сработает, если мод выключили.

Мод **может**: свои инструменты, снаряды, взрывы и беды; блоки, люди, предметы; свои предметы, материалы, здания, карты, звуки;
правила игры (гравитация, урон, сила взрывов…); счёт и надписи на экране; свои летающие и ползающие объекты (мод сам считает их
и рисует); команды консоли; данные в сохранении.

Мод **не может**: менять поведение жителей, управлять машиной, добавлять новые жидкости и новые окна интерфейса, менять физику
целиком, выходить в интернет.

## 4. Справочник: все команды пульта

Пульт `w` — объект, который мод получает в `setup(w)`. Ниже — всё, что в нём есть. Для каждой команды: что она делает, что принимает,
что возвращает и пример. Числа за пределами допустимого игра сама подрезает до ближайшего края.

### 4.1. Регистрация: добавить в игру

#### `w.addTool(описание)` — инструмент

Добавляет кнопку в ряд инструментов («Снос», «Стройка» или оба), перед ластиком. В редакторе карт инструментов модов нет.

| Поле | Что это |
|---|---|
| `id` | Короткое имя латиницей (обязательно) |
| `name` | Название под кнопкой, до 28 знаков (обязательно) |
| `hint` | Подсказка в панели инструмента, до 180 знаков |
| `mode` | `'destroy'` — в «Сносе» (так по умолчанию), `'build'` — в «Стройке», `'both'` — в обоих |
| `icon` | Значок: контур SVG (то, что пишется в `d="…"`) в поле 24 × 24, рисуется линией, как значки игры. Без него — общий значок модов |
| `slider` | Ползунок: `{ label, min, max, def, unit, format }`. `min`, `max`, `def` — целые от −999 до 999; `unit` — подпись после числа (`'кг'`); `format(v)` — своя подпись: вернуть строку |
| `down(p)` | Палец или кнопка мыши нажаты |
| `move(p)` | Ведут, не отпуская |
| `up(p)` | Отпустили |
| `update(dt, p)` | Каждый шаг игры, пока инструмент выбран (на паузе не зовётся). `dt` — 1/60 секунды |
| `draw(ctx, p)` | Каждый кадр, пока инструмент выбран: рисовать прицел, подсказку. `ctx` — холст в координатах мира |
| `select()`, `deselect()` | Инструмент выбрали, сменили на другой |

Указатель `p`: `x`, `y` — точка в мире; `down` — нажат ли; `vx`, `vy` — скорость движения; `startX`, `startY` — где нажали;
`value` — значение ползунка.

Внутри функций инструмента `this` — само описание: в нём удобно держать своё состояние (`this.count`). Стрелочные функции
(`() => …`) своего `this` не имеют — для состояния тогда объявите переменную в `setup`.

```js
w.addTool({
  id: 'line',
  name: { ru: 'Линия взрывов', en: 'Blast line' },
  hint: { ru: 'Тяните — взрывы встанут вдоль линии.', en: 'Drag — blasts follow the line.' },
  icon: 'M4 20L20 4M6 14l4 4M14 6l4 4',
  slider: { label: { ru: 'Шаг', en: 'Step' }, min: 10, max: 60, def: 24, unit: 'px' },
  down(p) { this.lastX = p.x; this.lastY = p.y; },
  move(p) {
    if (Math.hypot(p.x - this.lastX, p.y - this.lastY) < p.value) return;
    w.explode(p.x, p.y, 14, 120, { fire: 0 });
    this.lastX = p.x; this.lastY = p.y;
  },
  draw(ctx, p) {
    ctx.strokeStyle = 'rgba(255, 200, 60, 0.9)';
    ctx.lineWidth = 2 / w.camera.zoom;            // толщина в пикселях экрана при любом приближении
    ctx.beginPath(); ctx.arc(p.x, p.y, 8, 0, Math.PI * 2); ctx.stroke();
  },
});
```

В одном моде — до 24 инструментов.

#### `w.addCommand(имя, функция)` — команда консоли

Консоль открывается клавишей `~` (на телефоне — меню → «Консоль»). Имя — от 2 до 16 букв (русских или латинских), цифр, `-` и `_`.
Функция получает всё, что игрок написал после имени (маленькими буквами). Если она вернёт строку — игра покажет её сообщением.
Имя, занятое игрой или другим модом, — ошибка.

```js
w.addCommand('ливень', (arg) => {
  const n = Math.min(40, Number(arg) || 10);
  for (let i = 0; i < n; i++) {
    w.after(i * 0.1, () => {
      const c = w.camera;
      w.shoot({ x: c.left + Math.random() * (c.right - c.left), y: c.top - 40, vy: 300, look: 'ball', radius: 16, power: 150 });
    });
  }
  return 'Ливень из ' + n + ' снарядов';
});
```

#### `w.addSound(id, запись)` — свой звук

Запись вшивается в файл мода строкой `'data:audio/mp3;base64,…'` (подойдёт mp3, ogg, wav — любой формат, который читает браузер),
до 2 МБ. Играется командой `w.sound(id, …)`. Запись готовится в фоне долю секунды: сыгранная в первый миг после включения
мода промолчит. До 32 звуков в моде. Как получить такую строку из своего файла — раздел 6.10.

```js
w.addSound('beep', 'data:audio/mp3;base64,…');
```

#### `w.addItem(описание)` — предмет

Новый предмет во вкладке «Моды» инструмента «Предметы» («Стройка»). Ставится, двигается, падает, горит и ломается, как предметы игры.

| Поле | Что это | По умолчанию |
|---|---|---|
| `id`, `name` | Имя латиницей и название (обязательно) | |
| `width`, `height` | Размер в пикселях мира (обязательно): от 3 × 3 до 320 × 220. Клетка — 6 | |
| `mass` | Масса, от 0,2 до 300 (для сравнения: телевизор — 2, диван — 4, машина — 15) | 2 |
| `hp` | Прочность (от 1 до 3000) | 40 |
| `fragile` | Хрупкость к ударам (от 0,02 до 2) | 0,6 |
| `flammable` | Горючесть (от 0 до 1) | 0,3 |
| `value` | Цена: идёт в ущерб на табло, когда предмет разбит | 100 |
| `sound` | Звук удара: `'wood'`, `'metal'`, `'soft'`, `'glass'`, `'ceramic'`, `'stone'` | `'wood'` |
| `debris` | Обломки: `'wood'` (щепа), `'cloth'` (ткань), `'metal'`, `'glass'` (осколки), `'white'` (белая крошка), `'leaf'`, `'water'` (брызги) | по звуку: wood → `'wood'`, metal → `'metal'`, soft → `'cloth'`, glass → `'glass'`, ceramic и stone → `'white'` |
| `variants` | Сколько у предмета видов (до 8): игрок перебирает их в «Предметах» | 1 |
| `hang` | `true` — вешается на потолок над курсором (люстра, вывеска) | |
| `light` | Светит ночью: `{ x, y, radius }` — точка от центра предмета и радиус | |
| `explosive` | Взрывается, если разбит или загорелся: `{ radius, power, fire, fuse }` (`fuse` — секунды горения до взрыва) | |
| `draw(ctx, w, h, variant)` | Рисунок кодом: холст от 0 до `w` по ширине и от 0 до `h` по высоте | |
| `image` | Рисунок картинкой: `'data:image/png;base64,…'` (png, jpeg, webp, gif; до 1 МБ) | |
| `images` | Несколько картинок — по одной на вид (до 8) | |
| `onBreak(e)` | Своя функция «предмет разбит» (данные — как у события `itemBreak`) | |

Рисунок рисуется один раз и запоминается — не делайте его зависящим от времени. Маленькая картинка (точка на пиксель мира)
остаётся чёткой, крупная плавно уменьшается. Разбитый предмет рассыпается обломками вида `debris`. До 60 предметов в моде.

```js
w.addItem({
  id: 'barrel',
  name: { ru: 'Бочка с краской', en: 'Paint barrel' },
  width: 12, height: 16, mass: 4, hp: 40, sound: 'metal', flammable: 0.6, variants: 3,
  draw(ctx, pw, ph, v) {
    ctx.fillStyle = ['#d94f4f', '#4f8fd9', '#e0c040'][v];
    ctx.fillRect(0, 1, pw, ph - 2);
    ctx.fillStyle = '#2b2d31';
    ctx.fillRect(0, 0, pw, 1.5); ctx.fillRect(0, ph - 1.5, pw, 1.5);
  },
});
```

#### `w.addMaterial(описание)` — материал

Новый материал в «Кисти» («Стройка»). Материал мода — **копия готового материала-образца** (`like`) со своим цветом и числами:
у него текстура и звуки образца. Чего мод не задал — как у образца.

| Поле | Что это | Пределы |
|---|---|---|
| `id`, `name` | Имя латиницей и название (обязательно) | |
| `like` | Образец: любой материал кисти (список — раздел 10.1) | по умолчанию `'brick'` |
| `color` | Цвет: `'#rrggbb'` | |
| `density` | Плотность: вес блока (дерево 0,7, кирпич 1,9, сталь 1,4) | 0,1–8 |
| `hp` | Прочность к ударам и взрывам (дерево 60, бетон 150, сталь 320) | 2–2000 |
| `compress` | Сколько веса держит сверху (кирпич 900, бетон 2000) | 10–20000 |
| `shear` | Держит ли выступы и пролёты вбок (кирпич 28, сталь 400) | 1–5000 |
| `tension` | Держит ли подвешенное снизу (кирпич 8, сталь 1500) | 1–20000 |
| `flammable` | Горючесть | 0–1 |
| `burnTime` | Сколько секунд горит | 1–60 |
| `brittle` | Хрупкость: как легко крошится | 0,05–5 |
| `shatter` | На сколько частей колется упавший кусок | 0,1–4 |
| `bearing` | `false` — не несущий: на нём нельзя строить (как стекло) | |
| `value` | Цена блока для ущерба на табло | |
| `onBreak(e)` | Своя функция «блок разрушен» (данные — как у события `break`) | |

Особое поведение, привязанное к самому материалу игры, не переходит к копии: стекло лопается от ударной волны, сталь гнётся,
из железобетона торчит арматура — у материала мода этого нет, даже если он сделан по их образцу.

Номеров для материалов модов в игре 42 на все включённые моды. Если они кончились, мод работает без своего материала, а игрок
видит сообщение «выключите другой мод с материалами». Выключили мод — его блоки в мире становятся материалом-образцом.

```js
w.addMaterial({
  id: 'titan',
  name: { ru: 'Титан', en: 'Titanium' },
  like: 'steel', color: '#9fb0c4',
  density: 0.8, hp: 600, shear: 900, tension: 3000,
});
```

#### `w.addBuilding({ id, name, data })` — здание

Новый тип в инструменте «Здание». `data` — чертёж постройки, который даёт игра: «Копировать» → рамка → «В мод» → «Постройка
из рамки» (раздел 1). Сам чертёж писать не нужно. До 40 зданий в моде.

```js
w.addBuilding({ id: 'tower', name: { ru: 'Башня', en: 'Tower' }, data: TOWER });
```

(`TOWER` — строка данных из файла, который сделала игра; целиком — рецепт 6.9.)

#### `w.addMap({ id, name, data })` — карта

Карта в «Моих картах» с пометкой «мод». `data` — карта из редактора: «⋯» → «Сделать мод» → «Эта карта». До 20 карт в моде.

```js
w.addMap({ id: 'island', name: { ru: 'Остров', en: 'Island' }, data: ISLAND });
```

#### `w.on(событие, функция)` — подписаться на событие

Список событий и их данные — раздел 4.9. На одно событие — до 16 функций в моде.

```js
w.on('death', (e) => { w.toast('Погиб житель'); });
```

#### `w.findPeople({ x, y, radius, alive })` и `w.findItems({ x, y, radius, kind })`

Люди и предметы в круге (без `radius` — во всём мире; не больше 400). `alive: true` — только живые; `kind` — только предметы
этого вида (свой короткий `id` или имя предмета игры).

Человек: `{ id, x, y, vx, vy, hp, dead, down, burning, zombie, armed, panic, kind }` — номер, точка (пояс), скорость, здоровье 0–100,
погиб ли, лежит ли (упал, отброшен), горит ли, зомби ли, с оружием ли, в панике ли; `kind` — `'citizen'`, `'service'` (спасатели,
полиция, охрана, спецназ), `'bandit'`, `'zombie'`.

Предмет: `{ id, kind, x, y, angle, vx, vy, width, height, mass, hp, burning, hanging }` — номер, вид, центр, поворот, скорость,
размер, масса, доля прочности 0–1, горит ли, висит ли.

Номер `id` годится для команд «по номеру» (раздел 4.5). Поиск стоит времени: за шаг игры — не больше 24 поисков на мод.

```js
for (const h of w.findPeople({ x, y, radius: 120, alive: true })) {
  if (h.burning) w.water(h.x, h.y - 10, 2);       // потушить горящих
}
```

### 4.3. Блоки

`col`, `row` — клетка. Материал — имя из кисти (раздел 10.1) или короткий `id` материала своего мода.

| Команда | Что делает | Возвращает |
|---|---|---|
| `w.setBlock(col, row, материал)` | Ставит блок в пустую клетку (не в воду, не в предмет) | `true` — поставлен |
| `w.removeBlock(col, row, обломки)` | Убирает блок. `обломки = true` — разбивает с обломками, как удар; иначе блок просто исчезает. Грунт и скалу не убирает | `true` — убран |
| `w.damageBlock(col, row, урон)` | Снимает прочность (по умолчанию 50) | `true` — блок разрушен |

Железобетон ставится как `'rconcrete'`, а `getBlock` вернёт его как `'concrete'` с `reinforced: true` — это тот же блок.

```js
// стенка из кирпича высотой 5 клеток
for (let k = 0; k < 5; k++) w.setBlock(col, row - k, 'brick');
```

### 4.4. Взрывы, снаряды, огонь, вода

`x`, `y` — пиксели мира.

| Команда | Что делает |
|---|---|
| `w.explode(x, y, радиус, мощность, { fire, napalm, silent })` | Взрыв. Радиус 4–200 (по умолчанию 40), мощность 1–2000 (400). `fire` — сколько огня, 0–1 (0,4); `napalm: true` — горящая смесь; `silent: true` — без звука |
| `w.shoot(снаряд)` | Свой снаряд (ниже) |
| `w.bomb(x, y, радиус, мощность)` | Авиабомба падает сверху точно в точку, пробивает крышу и перекрытия до неё. По умолчанию 68 и 620 |
| `w.rocket(x0, y0, x1, y1, радиус, мощность)` | Ракета летит из точки (`x0`, `y0`) в сторону (`x1`, `y1`), пробивает наружную стену. По умолчанию 37 и 480 |
| `w.molotov(x, y, радиус)` | Коктейль Молотова, бросок сбоку. Радиус огня 10–90 (42) |
| `w.fire(x, y, сила)` | Поджечь блок в точке (или стену за ним). Сила 1–255 (140) |
| `w.water(x, y, количество)` | Налить воды: 1 — одна клетка (0,05–4) |
| `w.lava(x, y)` | Капля лавы |

Все возвращают `true`, если сработали.

```js
w.explode(x, y, 60, 700, { fire: 0.8 });
w.bomb(x, y);
w.rocket(w.camera.left, y - 100, x, y);
```

#### `w.shoot(снаряд)` — свой снаряд

Летит по дуге и взрывается, когда коснётся блока, земли или предмета, или по взрывателю `fuse`.

| Поле | Что это | По умолчанию |
|---|---|---|
| `x`, `y` | Откуда летит (обязательно) | |
| `vx`, `vy` | Скорость, пиксели в секунду (до 2500) | 0 |
| `gravity` | Множитель силы тяжести (от −3 до 3; 0 — по прямой) | 1 |
| `fuse` | Взорваться через столько секунд полёта (до 14; 0 — только от удара) | 0 |
| `radius`, `power` | Взрыв при попадании | 30 и 300 |
| `fire` | Огонь взрыва, 0–1 | 0,4 |
| `look` | Вид: `'shell'` (снаряд), `'bomb'`, `'rocket'`, `'ball'` (шарик) | `'shell'` |
| `color` | Цвет корпуса: `'#rrggbb'` | |
| `size` | Размер рисунка (0,3–6) | 1 |
| `spin` | Вращение в полёте (радианы в секунду) | 0 — смотрит по полёту |
| `trail` | След: `'smoke'` или `'fire'` | |
| `onHit(h)` | Своё вместо взрыва: `h` — `{ x, y, vx, vy }`, где и с какой скоростью попал | |
| `draw(ctx)` | Свой рисунок: холст уже стоит в точке снаряда и повёрнут по полёту | |

Снаряд живёт не дольше 14 секунд и исчезает, улетев за край мира.

```js
// снаряд-«матрёшка»: при попадании разлетается на три маленьких
w.shoot({
  x, y: y - 300, vy: 200, look: 'bomb', trail: 'smoke',
  onHit(h) {
    for (let i = -1; i <= 1; i++) w.shoot({ x: h.x, y: h.y - 4, vx: i * 160, vy: -220, look: 'ball', radius: 20, power: 200 });
  },
});
```

#### Взрыв точно в точке — даже в воздухе

Снаряд взрывается от удара: если игрок коснулся неба, снаряд пролетит мимо этой точки и взорвётся только о землю или стену.
Чтобы взрыв был ровно там, куда коснулись, нужны две вещи:

1. **`gravity: 0`** — снаряд летит по прямой. С силой тяжести он уходит вниз по дуге и мимо цели.
2. **`fuse` — время пути до точки:** расстояние, делённое на скорость. Снаряд взорвётся, когда долетит.

Если на пути стена или крыша, снаряд взорвётся о неё раньше: так и должно быть. Взрыватель срабатывает в конце шага игры
(1/60 секунды), поэтому промах — не больше пути за один шаг: при скорости 600 — около 10 пикселей, меньше двух клеток.

```js
// ракета прилетает слева сверху и взрывается ровно в точке (x, y)
const sx = x - 400, sy = y - 300;                 // откуда летит
const speed = 600;                                // пиксели в секунду
const dist = Math.hypot(x - sx, y - sy);          // сколько лететь
w.shoot({
  x: sx, y: sy,
  vx: (x - sx) / dist * speed,                    // скорость — вдоль прямой к цели
  vy: (y - sy) / dist * speed,
  gravity: 0,                                     // по прямой
  fuse: dist / speed,                             // долетела — взрыв
  look: 'rocket', radius: 40, power: 500,
});
```

Взрыватель — не больше 14 секунд: дальний старт при малой скорости не долетит. Тот же приём — в «Кассетной бомбе» (раздел 6.1):
она раскрывается в воздухе над целью. Своё летающее с другой траекторией (заход сбоку, потом пике) мод ведёт сам в `update`,
как НЛО в разделе 6.6, и взрывает командой `w.explode` там, где нужно.

### 4.5. Люди и предметы

```js
w.spawnItem('car', x, y - 20);
```

### 4.6. Большие беды, погода, день и ночь

Уровень — от 1 до 10, как ползунок у такого инструмента в игре. За шаг игры — не больше трёх бед (раздел 5).

| Команда | Что делает | Уровень по умолчанию |
|---|---|---|
| `w.meteor(x, y, размер)` | Метеорит падает в точку | 5 |
| `w.lightning(x, y, уровень)` | Молния | 6 |
| `w.quake(уровень)` | Землетрясение | 6 |
| `w.tornado(x, уровень)` | Смерч | 6 |
| `w.blackHole(x, y, уровень)` | Чёрная дыра | 5 |
| `w.tsunami(сторона, уровень)` | Цунами: `'left'` — волна слева, `'right'` — справа, без стороны — сама выберет (в порту — всегда с моря). Одно цунами за раз | 6 |
| `w.nuke(x, y, уровень)` | Ядерный удар: сирена, потом взрыв. Один за раз | 4 |
| `w.zombies(сколько, x)` | Толпа зомби (1–60) выходит из-за края экрана к точке `x`. Возвращает, сколько вышло | 12 |
| `w.setWeather(погода, сила)` | Погода: `'clear'`, `'rain'`, `'storm'`, `'fog'`, `'snow'`; сила 0–10 | |
| `w.setNight(true / false)` | Ночь или день | |

В редакторе карт погода и ночь не меняются.

```js
w.meteor(x, y, 3);
w.setWeather('storm', 8);
w.after(5, () => w.lightning(x, y));
```

### 4.7. Звук, экран, сообщения

| Команда | Что делает |
|---|---|
| `w.sound(имя, x, y, громкость, скорость)` | Звук в точке мира: свой (`addSound`) или игры (раздел 10.3). Громкость 0–1,5 (0,5), скорость 0,25–4 (1; больше — выше и короче). Нет такого звука — ошибка |


### 4.8. Правила игры («ручки»)

`w.set(имя, множитель)` меняет правило игры. **1 — как в игре**, 2 — вдвое больше, 0,5 — вдвое меньше. Если одну ручку
крутят несколько модов, множители перемножаются. Выключили мод — его правила вернулись. В меню «Моды» у мода видно, что он
поменял («Правила: гравитация ×0.5»).

| Имя | Что меняет | Пределы |
|---|---|---|
| `gravity` | Силу тяжести (поверх выбора игрока «1g / Луна / 0g») | 0–3 |
| `explosionPower` | Мощность всех взрывов | 0,1–5 |
| `explosionRadius` | Радиус всех взрывов | 0,25–3 |
| `blockDamage` | Урон блокам от ударов и взрывов | 0–10 |
| `itemDamage` | Урон предметам | 0–10 |
| `peopleDamage` | Урон людям (0 — никто не ранится и не гибнет; кроме испарённых ядерным взрывом) | 0–10 |
| `fallDamage` | Урон от падения | 0–10 |
| `fireSpread` | Как быстро расходится огонь | 0–5 |
| `buildingStrength` | Сколько веса держат постройки | 0,2–10 |
| `timeScale` | Скорость времени | 0,1–4 |

`w.get(имя)` — нынешний итог по ручке (со всеми модами). Неизвестное имя или число вне пределов — ошибка.

```js
w.set('gravity', 1 / 6);          // как на Луне
w.set('explosionPower', 2);       // все взрывы вдвое сильнее
w.toast('Гравитация ×' + w.get('gravity').toFixed(2));
```

### 4.9. События

`w.on(событие, функция)`. Данные события (`e`) — копия.

| Событие | Когда | Данные |
|---|---|---|
| `update` | Каждый шаг игры (60 раз в секунду; на паузе — нет) | `dt` — длина шага, секунды |
| `draw` | Каждый кадр | `ctx` — холст в координатах мира (под огнём и дымом) |
| `hud` | Каждый кадр, поверх всего | `ctx`, `width`, `height`, `free` — холст в пикселях экрана, его размер и часть экрана, свободная от панелей игры: `{ top, bottom, left, right }` |
| `explode` | **До** взрыва | `{ x, y, radius, power, fire }`: можно поменять `radius` и `power`; вернуть `false` — взрыва не будет |
| `break` | Блок разрушен | `{ col, row, x, y, material, cause, loose }`: клетка, точка, материал, причина (`'hit'` удар, `'blast'` взрыв, `'fire'` огонь, `'stress'` перегрузка, `'crush'` раздавлен, `'vapor'` испарён, `'other'`), `loose` — блок был в падающем куске |
| `itemBreak` | Предмет разбит | как предмет из `findItems` |
| `hurt` | Человек ранен (урон от 2) | как человек из `findPeople` и `{ cause, damage }` |
| `death` | Человек погиб | как человек из `findPeople` и `{ cause }` |
| `impact` | Тяжёлый обломок или предмет ударился о землю или постройку | `{ x, y, speed, mass, id, item }`: `item` — вид предмета или `''` для обломка |
| `world` | Новый мир: перезапуск, другая карта, загрузка сохранения | `{ map, seed, loaded, editor, data }`: `loaded` — из сохранения, `data` — что мод положил туда в `save` |
| `save` | Игрок сохраняет мир | мод **возвращает** свои данные: число, строку, список, простой объект |

Причины у `hurt` и `death` (`cause`): `'blast'`, `'blunt'`, `'fall'`, `'crush'`, `'fire'`, `'thermal'`, `'shock'`, `'electric'`,
`'gas'`, `'suffocation'`, `'hole'` и другие.

Как раздаются события:

- `update`, `draw`, `hud` и `explode` зовутся сразу. Остальные копятся и раздаются **в конце шага игры**. Поэтому взрыв, который
  мод устроил в ответ на событие, случится на следующем шаге: цепная реакция идёт сама и не вешает игру.
- Взрывы, которые мод устраивает прямо в обработчике `explode`, события `explode` не дают — иначе вышел бы бесконечный круг.
- За шаг игры — не больше 240 событий одного вида: при обвале в тысячу блоков лишние пропадают.
- Мод, включённый в идущей игре, событие `world` получит только со следующим миром — начальное состояние задавайте в `setup`.

```js
// взрывы в небе гасятся, у земли — вдвое сильнее
w.on('explode', (e) => {
  if (e.y < w.groundY(e.x) - 300) return false;
  e.power *= 2;
});
w.on('break', (e) => {
  if (e.material === 'glass' && Math.random() < 0.1) w.sound('glass', e.x, e.y, 0.3);
});
w.on('hud', (ctx, width, height, free) => {
  ctx.fillStyle = '#ffd23f';
  ctx.font = '600 14px sans-serif';
  ctx.fillText('Разрушено: ' + w.stats.destroyed.toFixed(1) + '%', free.left + 12, free.top + 16);
});
// тяжёлый обломок грохнулся — экран трясёт тем сильнее, чем тяжелее и быстрее
w.on('impact', (e) => {
  if (e.mass > 20 && e.speed > 300) w.shake(Math.min(0.6, e.mass * e.speed / 60000), e.x, e.y);
});
```

### 4.10. Своё хранилище

`w.store` — настройки и рекорды мода на устройстве игрока. Переживает перезапуск игры, выключение мода и его новую версию;
удаление мода стирает и хранилище.

| Команда | Что делает |
|---|---|
| `w.store.get(ключ, запасное)` | Значение по ключу; если его нет — `запасное` |
| `w.store.set(ключ, значение)` | Запомнить: число, строку, список, простой объект |
| `w.store.remove(ключ)` | Забыть |
| `w.store.keys()` | Список ключей |

Ключ — до 40 латинских букв, цифр, точек и чёрточек. До 64 ключей, одно значение — до 20 000 знаков.

```js
let best = w.store.get('best', 0);
w.on('death', () => {
  const n = w.stats.dead;
  if (n > best) { best = n; w.store.set('best', best); }
});
```

### 4.11. Сохранения

Хранилище (4.10) — для мода на этом устройстве. **Для мира** — событие `save`: что мод вернёт, ляжет в сохранение мира (до 60 000
знаков), а при загрузке придёт в событии `world` (`e.loaded === true`, `e.data`).

```js
let score = 0;
w.on('death', () => { score++; });
w.on('save', () => ({ score }));
w.on('world', (e) => { score = e.loaded && e.data ? e.data.score : 0; });
```

Сохранение помнит, какие моды были включены и сколько их вещей в мире. Если игрок загрузит его без мода, игра предупредит: предметы
мода убираются, его материалы становятся материалами-образцами — сохранение открывается всегда. Своя карта из редактора помнит
моды, чьи предметы и материалы стоят на ней.

## 5. Пределы и безопасность

### 5.1. Запас действий на шаг игры

Чтобы мод с ошибкой в цикле не подвесил игру, у команд есть запас на один шаг игры (1/60 секунды). Запас — общий на строку
таблицы: 6000 — на все блоки, огонь, воду и лаву вместе, 80 — на все снаряды вместе, и так далее. Кончился — команда возвращает
`false` до следующего шага. На паузе запас обновляется каждый кадр.

| Что | За шаг |
|---|---|
| Взрывы (`explode`) | 30 |
| Снаряды (`shoot`, `bomb`, `rocket`, `molotov`) | 80 |
| Люди (`spawnPerson`) | 12 |
| Предметы (`spawnItem`) | 30 |
| Блоки, огонь, вода, лава (`setBlock`, `removeBlock`, `damageBlock`, `fire`, `water`, `lava`) | 6000 |
| Большие беды и погода | 3 |
| Звуки (`sound`) | 12 |
| Действия над людьми и предметами по номеру | 300 |
| Поиски (`findPeople`, `findItems`) | 24 |

Нужно больше — растяните по времени: `w.after(i * 0.1, …)` или по шагам в `update`.

### 5.2. Размеры

| Что | Предел |
|---|---|
| Файл мода | 4 МБ |
| Одна запись звука | 2 МБ |
| Одна картинка | 1 МБ |
| Один чертёж здания | 1,5 МБ |
| Инструментов / предметов / звуков / зданий / карт в одном моде | 24 / 60 / 32 / 40 / 20 |
| Обработчиков одного события в моде | 16 |
| Хранилище мода | 64 ключа по 20 000 знаков |
| Данные мода в сохранении мира | 60 000 знаков |
| Материалов модов на всю игру | 42 |

### 5.3. Ошибки и автовыключение

- Ошибка в коде мода не роняет игру: игрок видит сообщение «Мод «…»: ошибка — …» (не чаще раза в 2,5 секунды), игра идёт дальше.
- **5 ошибок за 20 секунд — мод выключается сам**: «Мод «…» выключен: слишком много ошибок». Включить снова — в меню «Моды».
- Ошибка в `setup` не даёт моду включиться; при запуске игры такой мод выключается («Мод «…» не запустился и выключен»).
- Выключение мода убирает всё, что он добавил: инструменты, команды, предметы (и из мира), материалы (блоки становятся образцом),
  здания, карты, звуки, правила. Перезапускать игру не нужно.

### 5.4. Безопасность

Мод — это программа. Он работает внутри игры и не видит ни страницу, ни интернет, ни файлы устройства: всё это в коде мода
заменено пустыми именами. Но это не полная защита — поэтому игра показывает предупреждение перед первым запуском мода,
а ставить стоит только моды из мест, которым вы доверяете.

### 6.1. Кассетная бомба

Бомба раскрывается в воздухе и засыпает улицу зарядами. Снаряд со взрывателем по времени и своим `onHit`.

```js
Wreck.mod({
  id: 'cluster-bomb',
  name: { ru: 'Кассетная бомба', en: 'Cluster bomb' },
  author: 'ItsLamba',
  version: '1.0',
  api: 1,
  description: { ru: 'Бомба раскрывается в воздухе и засыпает улицу мелкими зарядами.', en: 'The bomb opens in the air and showers the street with bomblets.' },

  setup(w) {
    w.addTool({
      id: 'cluster',
      name: { ru: 'Кассетная бомба', en: 'Cluster bomb' },
      hint: { ru: 'Коснитесь цели — бомба раскроется над ней.', en: 'Tap a target — the bomb opens above it.' },
      slider: { label: { ru: 'Зарядов', en: 'Bomblets' }, min: 4, max: 24, def: 12 },

      down(p) {
        const n = p.value;
        const top = Math.min(w.camera.top - 60, p.y - 500);          // бомба появляется выше кадра
        w.shoot({
          x: p.x, y: top, vx: 0, vy: 420, look: 'bomb', size: 1.4,
          fuse: Math.max(0.3, (p.y - 160 - top) / 520),              // раскрыться метрах в десяти над целью
          onHit(h) {                                                 // вместо обычного взрыва — своё
            w.explode(h.x, h.y, 16, 80, { fire: 0 });
            for (let i = 0; i < n; i++) {
              w.shoot({
                x: h.x, y: h.y, look: 'ball', spin: 9, trail: 'smoke',
                vx: (i - (n - 1) / 2) * 34 + (Math.random() - 0.5) * 30,
                vy: 120 + Math.random() * 120,
                radius: 26, power: 260,
              });
            }
          },
        });
      },

      draw(ctx, p) {                                                 // прицел под курсором
        ctx.strokeStyle = 'rgba(255, 90, 60, 0.9)';
        ctx.lineWidth = 2 / w.camera.zoom;
        ctx.beginPath(); ctx.arc(p.x, p.y, 14, 0, 6.3); ctx.stroke();
      },
    });
  },
});
```

### 6.2. Мина с таймером

Касание ставит заряд, над ним идёт обратный отсчёт, по нулю — взрыв. Своё состояние, `update` и `draw`.

```js
Wreck.mod({
  id: 'timer-mine',
  name: { ru: 'Мина с таймером', en: 'Timer mine' },
  author: 'ItsLamba',
  version: '1.0',
  api: 1,
  description: { ru: 'Заряды с обратным отсчётом.', en: 'Charges with a countdown.' },

  setup(w) {
    const mines = [];                                    // поставленные заряды: { x, y, t } — t секунд до взрыва

    w.addTool({
      id: 'mine',
      name: { ru: 'Мина с таймером', en: 'Timer mine' },
      hint: { ru: 'Коснитесь стены или земли. Ползунок — секунды до взрыва.', en: 'Tap a wall or the ground. Slider — seconds to blast.' },
      slider: { label: { ru: 'Таймер', en: 'Timer' }, min: 1, max: 15, def: 5, unit: { ru: 'с', en: 's' } },
      down(p) {
        if (mines.length >= 20) { w.toast(w.lang === 'ru' ? 'Не больше 20 мин' : '20 mines at most'); return; }
        mines.push({ x: p.x, y: p.y, t: p.value });
        w.sound('click', p.x, p.y, 0.6);
      },
    });

    // каждый шаг игры: таймеры идут только в игре, на паузе стоят
    w.on('update', (dt) => {
      for (let i = mines.length - 1; i >= 0; i--) {
        const m = mines[i], sec = Math.ceil(m.t);
        m.t -= dt;
        if (m.t <= 0) { w.explode(m.x, m.y, 45, 500); mines.splice(i, 1); }
        else if (Math.ceil(m.t) < sec) w.sound('tink', m.x, m.y, 0.4);      // тик раз в секунду
      }
    });

    // каждый кадр: заряд и цифры над ним. Холст — в координатах мира, поэтому размер шрифта делим на приближение:
    // цифры на экране всегда около 12 точек, как ни приближай
    w.on('draw', (ctx) => {
      const k = 1 / w.camera.zoom;
      ctx.font = '700 ' + (12 * k).toFixed(2) + 'px sans-serif';
      ctx.textAlign = 'center';
      for (const m of mines) {
        ctx.fillStyle = '#c0392b'; ctx.fillRect(m.x - 4, m.y - 3, 8, 6);
        ctx.fillStyle = '#ffd23f'; ctx.fillText(String(Math.ceil(m.t)), m.x, m.y - 4 - 3 * k);
      }
    });

    w.on('world', () => { mines.length = 0; });          // новый мир — старых мин нет
  },
});
```

### 6.3. Мини-игра: снеси квартал тремя бомбами

Три бомбы, цель — разрушить заданную долю города. Счёт на экране, победа, поражение и рекорд на устройстве.

```js
Wreck.mod({
  id: 'three-bombs',
  name: { ru: 'Три бомбы', en: 'Three bombs' },
  author: 'ItsLamba',
  version: '1.0',
  api: 1,
  description: { ru: 'Мини-игра: снесите 3% города тремя бомбами.', en: 'Mini game: wreck 3% of the city with three bombs.' },

  setup(w) {
    const ru = w.lang === 'ru';
    const GOAL = 3;                                      // цель: процент разрушенного (сверх того, что было до начала)
    let left, start, lastAt, state;                      // бомб осталось, разрушено до начала, время последней бомбы, 'play' / 'win' / 'lose'
    let best = w.store.get('best', 0);                   // рекорд — лучший результат в процентах

    function reset() { left = 3; start = w.stats.destroyed; lastAt = -1; state = 'play'; }
    reset();
    w.on('world', reset);
    const got = () => Math.max(0, w.stats.destroyed - start);

    w.addTool({
      id: 'bomb3',
      name: { ru: 'Три бомбы', en: 'Three bombs' },
      hint: { ru: 'Сбросьте три бомбы так, чтобы снести как можно больше. Касание после конца — новая попытка.',
              en: 'Drop three bombs to wreck as much as you can. Tap after the end to retry.' },
      down(p) {
        if (state !== 'play') { reset(); w.toast(ru ? 'Новая попытка' : 'New try'); return; }
        if (left <= 0) return;
        left--;
        lastAt = w.world.time;
        w.bomb(p.x, p.y, 90, 1000);
      },
    });

    w.on('update', () => {
      if (state !== 'play') return;
      if (got() >= GOAL) state = 'win';
      else if (left === 0 && w.world.time - lastAt > 8) state = 'lose';    // восемь секунд на обрушение после последней бомбы
      else return;
      if (got() > best) { best = got(); w.store.set('best', best); }
      w.toast(state === 'win' ? (ru ? 'Победа!' : 'You win!') : (ru ? 'Не хватило. Ещё раз?' : 'Not enough. Again?'));
      w.sound(state === 'win' ? 'horn' : 'thud', w.camera.x, w.camera.y, 0.7);
    });

    w.on('hud', (ctx, width, height, free) => {
      const text = (ru ? 'Бомб: ' : 'Bombs: ') + left + (ru ? ' · снесено ' : ' · wrecked ') + got().toFixed(1) + '% / ' + GOAL + '%'
        + (ru ? ' · рекорд ' : ' · best ') + best.toFixed(1) + '%';
      ctx.font = '600 14px system-ui, sans-serif';
      ctx.textAlign = 'center';
      const tw = ctx.measureText(text).width + 24;
      ctx.fillStyle = state === 'win' ? 'rgba(30, 110, 50, 0.85)' : state === 'lose' ? 'rgba(130, 30, 30, 0.85)' : 'rgba(20, 22, 28, 0.75)';
      ctx.fillRect(width / 2 - tw / 2, free.top, tw, 26);
      ctx.fillStyle = '#fff';
      ctx.fillText(text, width / 2, free.top + 18);
    });
  },
});
```

### 6.4. Лунная гравитация

### 6.6. НЛО: свой летающий объект

Игра не знает про НЛО: мод сам двигает его в `update`, рисует в `draw` и действует на мир командами пульта. Тарелка летит к точке

```js
  version: '1.0',
  api: 1,
  description: { ru: 'Летающая тарелка поднимает людей лучом.', en: 'A flying saucer lifts people with a beam.' },

  setup(w) {

    w.addTool({
      id: 'ufo',
      name: { ru: 'НЛО', en: 'UFO' },
      hint: { ru: 'Коснитесь — тарелка прилетит сюда.', en: 'Tap — the saucer flies here.' },
      icon: 'M3 13c3-2 15-2 18 0c-3 3-15 3-18 0zM8 11c0-4 8-4 8 0M8 17l-2 4M16 17l2 4',
      down(p) {
        if (!ufo) ufo = { x: w.camera.left - 80, y: w.camera.top + 60, t: 0, beam: false, pull: 0 };
        ufo.tx = p.x;
      },
    });

    w.on('update', (dt) => {
      if (!ufo) return;
      const hover = Math.min(w.topY(ufo.tx), w.groundY(ufo.tx)) - 110;     // висеть над крышами
      const dx = ufo.tx - ufo.x;
      ufo.x += Math.max(-260 * dt, Math.min(260 * dt, dx));
      ufo.y += (hover - ufo.y) * Math.min(1, dt * 2);
      ufo.t += dt;
      ufo.beam = Math.abs(dx) < 6;
      // луч: раз в 0,2 секунды поднять живых под тарелкой (поиск людей — не каждый шаг: он стоит времени)
      ufo.pull -= dt;
      if (ufo.beam && ufo.pull <= 0) {
        ufo.pull = 0.2;
        for (const h of w.findPeople({ x: ufo.x, y: ufo.y + 90, radius: 110, alive: true })) {
          if (Math.abs(h.x - ufo.x) < 26 && h.y > ufo.y) w.pushPerson(h.id, (ufo.x - h.x) * 3, -240);
        }
      }
    });

    w.on('draw', (ctx) => {
      if (!ufo) return;
      const { x, y } = ufo;
      if (ufo.beam) {
        const g = ctx.createLinearGradient(0, y, 0, y + 200);
        g.addColorStop(0, 'rgba(140, 255, 180, 0.45)');
        g.addColorStop(1, 'rgba(140, 255, 180, 0)');
        ctx.fillStyle = g;
        ctx.beginPath(); ctx.moveTo(x - 8, y); ctx.lineTo(x + 8, y); ctx.lineTo(x + 30, y + 200); ctx.lineTo(x - 30, y + 200); ctx.fill();
      }
      ctx.fillStyle = '#9aa6b2';
      ctx.beginPath(); ctx.ellipse(x, y, 26, 7, 0, 0, Math.PI * 2); ctx.fill();
      ctx.fillStyle = 'rgba(160, 220, 255, 0.85)';
      ctx.beginPath(); ctx.ellipse(x, y - 5, 10, 8, 0, Math.PI, 0); ctx.fill();
      ctx.fillStyle = Math.floor(ufo.t * 4) % 2 ? '#ffd23f' : '#ff5a3c';     // мигающие огни
      for (let i = -2; i <= 2; i++) { ctx.beginPath(); ctx.arc(x + i * 9, y + 2, 1.6, 0, Math.PI * 2); ctx.fill(); }
    });

    w.addCommand('нло', () => { ufo = null; return 'НЛО улетело'; });
    w.on('world', () => { ufo = null; });
  },
});
```

### 6.7. Динамит: блок, который взрывается

Материал со своим `onBreak`: разрушенный блок взрывается, взрыв ломает соседние блоки динамита — стена рвётся цепочкой.
Взрыв из `onBreak` случается на следующем шаге игры, поэтому цепочка идёт сама и не вешает игру. Полная версия с рекордом
цепочки — файл [examples/dynamite.wmod](examples/dynamite.wmod) рядом с этим документом.

```js
Wreck.mod({

  name: { ru: 'Блоки динамита', en: 'Dynamite blocks' },
  author: 'ItsLamba',
  version: '1.0',
  api: 1,
  description: { ru: 'Материал «Динамит» в «Кисти»: рвётся цепочкой.', en: 'Dynamite material in the Brush: blows up in a chain.' },

  setup(w) {
    let booms = 0;
    w.addMaterial({
      id: 'tnt',
      name: { ru: 'Динамит', en: 'Dynamite' },
      like: 'wood', color: '#c0392b', hp: 30,
      onBreak(e) { booms++; w.explode(e.x, e.y, 34, 380, { fire: 0.2 }); },
    });
    w.addCommand('динамит', () => 'Взорвалось блоков: ' + booms);
  },
});
```

### 6.10. Свой звук

Запись вшивается в файл строкой base64. Как её получить:

- **Windows:** откройте PowerShell в папке с файлом и выполните (строка окажется в буфере обмена):
  `"data:audio/mp3;base64," + [Convert]::ToBase64String([IO.File]::ReadAllBytes("$PWD\gudok.mp3")) | Set-Clipboard`
- **macOS:** в Терминале `echo "data:audio/mp3;base64,$(base64 -i gudok.mp3)" | pbcopy`
- **Linux:** `echo "data:audio/mp3;base64,$(base64 -w0 gudok.mp3)"`

Для ogg пишите `data:audio/ogg;base64,`, для wav — `data:audio/wav;base64,`. Короткие записи лучше: файл мода растёт на треть
больше самой записи. Берите только записи, которые вам разрешено использовать.

```js
  api: 1,
  description: { ru: 'Инструмент «Гудок» со своей записью.', en: 'A horn tool with its own sound.' },

  setup(w) {
    w.addSound('honk', HONK);
    w.addTool({
      id: 'honk',
      name: { ru: 'Гудок', en: 'Horn' },
      hint: { ru: 'Коснитесь — гудок. Ползунок — высота звука.', en: 'Tap to honk. Slider — pitch.' },
      slider: { label: { ru: 'Высота', en: 'Pitch' }, min: 5, max: 20, def: 10 },
      down(p) {
        w.sound('honk', p.x, p.y, 0.9, p.value / 10);
        for (const h of w.findPeople({ x: p.x, y: p.y, radius: 80, alive: true })) w.pushPerson(h.id, h.x < p.x ? -200 : 200, -150);
      },
    });
  },
});
const HONK = 'data:audio/mp3;base64,…';   // сюда — ваша запись
```

## 7. Отладка и частые ошибки

### 7.1. Как смотреть, что делает мод

- **`w.toast(текст)`** — самый простой способ: сообщение внизу экрана. Работает везде, и на телефоне.
- **Команда консоли.** Добавьте моду команду, которая показывает его состояние, и вызывайте её клавишей `~` (на телефоне —
  меню → «Консоль»): `w.addCommand('мой', () => 'мин: ' + mines.length)`.
- **`w.log(…)`** пишет в консоль разработчика браузера (F12 → Console), с пометкой `[mod id]`. Работает только в браузерной
  версии игры; в версии для Windows и на телефоне консоли разработчика нет.
- **Меню «Моды»**: у мода видно, что он добавил, и последнюю ошибку («Ошибка: …»).

### 7.2. Ошибки при добавлении мода

Игра пишет «Не удалось добавить мод: …» и одну из причин:

| Сообщение | Что не так |
|---|---|
| файл пустой | В файле нет текста |
| файл слишком большой | Больше 4 МБ — уменьшите картинки и звуки |
| ошибка в коде — … | Опечатка, из-за которой файл не читается: лишняя или пропущенная скобка, запятая, кавычка. После тире — подсказка браузера (обычно по-английски) |
| это не мод Wreckbox: в файле нет Wreck.mod({ … }) | Нет вызова `Wreck.mod` или в нём нет `setup` |
| в моде не указана версия формата (api: 1) | Забыли `api: 1` |
| мод сделан для более новой версии игры — обновите игру | `api` больше, чем понимает эта версия игры |
| у мода нет названия (name) | Нет `name` |
| ошибка при запуске — … | `setup` упал: после тире — что именно (например, «addTool: нужны id (латиницей) и name») |

Пример — забыт `api`:

<!-- test: error "в моде не указана версия формата (api: 1)" -->
```js
Wreck.mod({
  id: 'no-api',
  name: 'Без версии',
  setup(w) { w.toast('Привет'); },
});
```

Пример — у инструмента нет `id`, мод не запускается:

<!-- test: error "addTool: нужны id (латиницей) и name" -->
```js
Wreck.mod({
  id: 'no-tool-id',
  name: 'Инструмент без имени',
  api: 1,
  setup(w) {
    w.addTool({ name: 'Бах', down(p) { w.explode(p.x, p.y, 30, 300); } });
  },
});
```

### 7.3. Ошибки во время игры

Игра пишет «Мод «…»: ошибка — …». Частые тексты (их пишет браузер, по-английски):

| Текст | Причина | Что делать |
|---|---|---|
| `w.explod is not a function` | Опечатка в имени команды | Сверьте с разделом 4 |
| `x is not defined` | Переменная не объявлена или объявлена в другой функции | Объявите `let x` в `setup` |
| `Cannot read properties of undefined (reading 'x')` | Берёте поле у того, чего нет: пустой результат, нет такого человека | Проверьте: `if (b) …` |
| `Cannot read properties of null` | `getBlock` вернул `null` — клетка пустая | Проверьте результат |
| `window is not defined`, `document is not defined` | Мод не видит страницу | Делайте всё через пульт |
| `fetch is not defined` | Мод не выходит в интернет | — |
| `sound: нет звука «…»` | Нет такого звука | Список — `w.sounds` и раздел 10.3 |
| `setBlock: нет материала «…»` | Нет такого материала | Список — `w.materials` и раздел 10.1 |
| `spawnItem: нет предмета «…»` | Нет такого предмета | Список — `w.items` и раздел 10.2 |
| `set: «gravity» — нужно число от 0 до 3` | Число вне пределов ручки | Раздел 4.8 |

Если ошибки идут часто (5 за 20 секунд), мод выключится сам — включите его снова в меню «Моды», когда исправите.

### 7.4. Если ничего не происходит

- Команда вернула `false` — посмотрите, почему (раздел 3.6): клетка занята, точка за краем мира, кончился запас на шаг (раздел 5.1).
- `update` не зовётся на паузе — снимите паузу.
- Инструмент не виден — он в «Сносе» или «Стройке», смотря по `mode`; в редакторе карт инструментов модов нет.
- Предмет не появился в «Предметах» — он во вкладке «Моды».
- Своя запись молчит в первый миг после включения мода — она ещё готовится.
- Событие `world` не пришло — мод включён в идущей игре; оно придёт со следующим миром.

## 8. Для нейросети

### 8.1. Как попросить нейросеть сделать мод

1. Приложите к сообщению этот файл (`MODDING.md`) целиком.
2. Вставьте текст из 8.4 и опишите своими словами, какой мод нужен.
3. Нейросеть пришлёт файл. Сохраните его как `.wmod` и поставьте (раздел 2.2).
4. Если игра пишет ошибку — отправьте нейросети её текст целиком: «Игра пишет: …».

Не отправляйте нейросети саму игру: мод, сделанный по этому документу, переживает обновления игры и ставится рядом с другими
модами, а переделанная копия игры — нет.

### 8.2. Правила для нейросети

Если ты — нейросеть и тебя просят сделать мод для Wreckbox, держись этих правил:

1. **Пиши только через пульт `w`** из раздела 4. Не выдумывай команды, поля, события, имена материалов, предметов и звуков:
   если чего-то нет в этом документе — этого нет в игре. Имена материалов, предметов и звуков — только из раздела 10.
2. **Не обращайся к игре и странице напрямую**: в моде нет `window`, `document`, `fetch`, `localStorage`, `setTimeout` для дел
   в игре. Отложенное — `w.after`, каждый шаг — `w.on('update')`, рисунок — `w.on('draw')` или `w.on('hud')`.
3. **Ответ — один файл `.wmod` целиком** в одном блоке кода: `Wreck.mod({ id, name, author, version, api: 1, description, setup(w) { … } })`.
   Не присылай кусками и не пиши «остальное без изменений».
4. **`id` — латиницей**, уникальный для мода и для каждого вида внутри него. Всё, что видит игрок, — на двух языках `{ ru, en }`.
5. **Помни про пределы** (раздел 5): запас действий на шаг, размеры. Не делай в `update` того, что тяжело делать 60 раз в секунду
   (поиск людей каждый шаг по всему миру, сотни взрывов). Растягивай по времени.
6. **Чего игра не умеет** (раздел 3.7) — скажи честно и предложи самое близкое, что можно сделать пультом.
7. Комментарии в коде — на языке человека, который просит. Объясни в двух-трёх предложениях после кода, как мод поставить
   и где искать то, что он добавил.

### 8.3. Проверь перед ответом

- [ ] Файл начинается с `Wreck.mod({` и заканчивается `});`, скобки и запятые на месте.
- [ ] Есть `name`, `api: 1` и `setup(w)`; `id` латиницей.
- [ ] Каждая команда, поле и событие есть в разделе 4; каждое имя материала, предмета и звука — в разделе 10 (или это свой `id`).
- [ ] У каждого инструмента, предмета, материала, звука — свой `id` и `name`.
- [ ] Числа в пределах таблиц (радиус взрыва до 200, мощность до 2000, уровень бед 1–10).
- [ ] Нет `window`, `document`, `fetch`, `localStorage`, `setTimeout`, `setInterval`.
- [ ] Состояние, которое меняется, хранится в переменных `setup`; новый мир сбрасывает его (`w.on('world', …)`), если нужно.
- [ ] Картинки и звуки — вшитые строки `data:…;base64,…` (если человек их не прислал — рисуй кодом и используй звуки игры).
- [ ] Взрыв должен быть там, куда коснулись, — снаряд с `gravity: 0` и `fuse` (4.4, «Взрыв точно в точке») или своё летающее
      в `update` с `w.explode` в нужной точке. Обычный снаряд взрывается только от удара и пролетит мимо точки в воздухе.

### 8.4. Готовый текст просьбы

Скопируйте, допишите последний абзац и отправьте вместе с файлом `MODDING.md`:

## 9. Совместимость и правила

### 9.1. Версии

- `api: 1` — первая версия формата модов (Wreckbox 2.0). Пока игра понимает `api: 1`, команды из этого документа **не пропадают
  и не переименовываются**: мод, сделанный сегодня, работает и в следующих версиях игры.
- Новые команды появляются в пульте по мере выхода версий. Если мод использует новую команду, а игрок ещё не обновился, проверьте,
  есть ли она: `if (w.newCommand) …`. Версия игры — `w.game`.
- Мод с `api` больше, чем понимает игра, не ставится: «мод сделан для более новой версии игры — обновите игру».
- Моды не обновляются сами: новую версию игрок ставит так же, как первую, — с тем же `id` она заменит прежнюю.

### 9.2. Правила

- Делать моды и делиться ими можно **бесплатно**.
- Нельзя: продавать моды; выдавать мод за официальную версию игры; выкладывать саму игру, целиком или переделанную.
- Пишите в моде своё имя (`author`) и не выдавайте чужой мод за свой. Взяли чужое — укажите автора.
- Мод должен делать то, что о нём написано. Не прячьте в моде того, о чём игрок не знает.
- Картинки и звуки — только те, которые вам разрешено использовать.
- Делитесь файлом `.wmod` там, где собирается сообщество игры (ссылки — в меню игры).

`getBlock` и событие `break` называют материал так же, а ещё могут вернуть то, что мод поставить не может: `'earth'` (грунт),
`'rock'` (скала), `'lava'`, `'basalt'`, `'rebar'` (арматура), `'ice'` (лёд). Железобетон там — `'concrete'` с `reinforced: true`.
Материал мода называется полным именем: `mod_<id мода>_<id материала>`.
